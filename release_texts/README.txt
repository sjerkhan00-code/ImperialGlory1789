IMPERIAL GLORY 1789 - version 1.0.0
A world campaign mod for Imperial Glory (2005) by Treseed.

WHAT IT IS
* The 1805 Europe campaign becomes a 1789 world campaign: Europe, Asia and
  Africa, 280 provinces, in the game's own art style.
* 29 playable nations, among them Qing China, Japan, the Marathas, Ethiopia,
  Persia, Arabia, Turkestan and the Kazakh Khanate.
* 1789 borders, armies, fleets, alliances and wars. New uniforms, flags and
  battlefields.
* Crash fixes, much faster AI turns, quality-of-life changes and an
  optional Cheats menu (player only).
* All new texts in the 8 game languages.

REQUIREMENTS
* Imperial Glory v1.1 (Steam) with its original data.pak, Data1.pak and
  Text.pak. This download contains no original game files.
* Windows 10 or 11. No internet needed.

INSTALL
1. Extract the archive anywhere.
2. Run Install.bat and choose 1. It finds the game (or asks for the folder),
   writes ImperialGlory_ModNations.exe and builds Data2.pak from your own
   game files (about a minute). It works offline, backs up what it replaces
   and never changes ImperialGlory.exe.
3. Start ImperialGlory_ModNations.exe (or the desktop shortcut) and begin a
   NEW campaign.
* "Cannot write to the game folder": run Install.bat as administrator.
* "Not the original v1.1 file": verify the game files in Steam, try again.

UNINSTALL
Run Uninstall.bat. It removes the mod and restores its backups.

GOOD TO KNOW
* Always start a new campaign. Saves do not work across modded/unmodded.
* The original exe also loads Data2.pak: uninstall to play the unmodded game.
* Not compatible with other mods that use Data2.pak or patch the exe.
* Fullscreen sizes up to 3840x2160 are in Options.
* Optional: dgVoodoo2 by Dege (not included, http://dege.freeweb.hu/dgVoodoo2/)
  gives better image quality. Use Direct3D 11 output: Direct3D 12 and
  "fake fullscreen" make the game exit.
